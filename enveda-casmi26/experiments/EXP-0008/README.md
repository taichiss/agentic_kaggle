## LB への見込み (EXP-0002 のクラス構成で試算、未検証)

ΔLB ≈ p1·Δ(Class 1) + p2·Δ(Class 2) + p3·r·M(救済後)、p1 = 0.148、p2 = 0.285、p3 = 0.567

- A: Δ ≈ 0.148 × (+0.004) + 0.285 × (0.000) + 0.567 × r × 0.186 ≈ +0.001 + 0.105·r
- B: Δ ≈ 0.148 × (−0.005) + 0.285 × (−0.014) + 0.567 × r × 0.498 ≈ −0.005 + 0.282·r
- r (hidden test の pool 外の分子のうち PubChemLite にあるもの) が分からないので幅を持たせると、r = 30% で A +0.033 / B +0.080

## LB 提出 — 提出前の予測 (2026-10-28 記入、結果を見る前に固定)

| 提出 | kernel | 候補 pool | 前回 LB (V17 pool) |
|---|---|---|---:|
| A 固定融合 | `yuitomurano/casmi26-exp0008-a-fusion` | 改善後 (本 README) | 0.191 |
| B analog 単独 | `yuitomurano/casmi26-exp0008-b-analog` | 改善後 (本 README) | 0.247 |

ランカーは EXP-0001 の A / B と同じ。差分は候補 pool だけ。

**モデル (上の試算と同じ):** r = hidden test の pool 外の分子のうち、正解が PubChemLite にある割合

- ΔA = LB_A − 0.191 ≈ +0.001 + 0.105·r
- ΔB = LB_B − 0.247 ≈ −0.005 + 0.282·r

**予測:** r は 0.3〜0.9 (pool 外が NP パネルに近い天然物なら高く、未収載の新規化合物が多ければ低い)。
→ LB_A ≈ 0.22〜0.29、LB_B ≈ 0.33〜0.50

**判定:**
- 2 本それぞれから r を逆算する (r_A = (ΔA − 0.001) / 0.105、r_B = (ΔB + 0.005) / 0.282)
- Public LB の SE ±0.03 から、r_B の不確かさは ±0.1 程度、r_A は ±0.3 程度。r の推定は主に B で行い、A は整合性の確認に使う
- r_A と r_B が不確かさの範囲で一致すれば、EXP-0002 のクラス構成モデルは引き続き使える。大きく食い違えばモデルを見直す
- ΔB < +0.03 (r ≲ 0.1) なら、hidden test の pool 外の分子は PubChemLite にもほぼない → より大きな DB (COCONUT 完全版・PubChem) か de novo 生成が要る

### 解釈の候補 (どちらかはまだ区別できない)

1. **pool 外は本当に 57% あるが、PubChemLite (38.6 万構造) より大きな DB にしかない。** 公開 kernel (LB 0.44–0.47) は PubChem 全体 (約 1 億構造) を popularity prior 付きで混ぜている
2. **EXP-0002 のクラス構成モデル自体がずれている。** 未知数 2 つに式 2 本でちょうど解けていたので検定にならなかった。CV と LB の差は pool 外ではなく、hidden test のスペクトル自体が CV より難しい (分布の違い) ことでも説明できる。その場合、pool を広げても LB は動かない

今回の提出は、1 を「PubChemLite の範囲では」否定した。2 を確かめるには、pool 外の割合を別の手段で測る必要がある (例: PubChem tier を混ぜた提出で LB が動くか、公開 kernel の PubChem 統合前後の LB 差)

## 公開 kernel の記録による切り分け (2026-10-29、追加提出なし)

出典: `doc/kernel/2026/casmi26/raw/` の公開 notebook (dmitriigluzdov の 2 本)

- **アブレーション:** Public LB 0.464 の kernel から「PubChem にしかない候補」(train 構造にも COCONUT にもない候補) を外すと **0.409 (−0.055)**。作者の結論は「public test の正解の多くは train 構造と COCONUT の外の候補でしか届かない」。Public LB では 1 分子 ≈ 0.008 なので 7 分子分前後
- **版ごとの LB:** PubChemLite 追加の v13 で 0.341、PubChem 検索 (約 1 億 500 万構造) の v17 で 0.366、ショートリストの深掘り (1,000 → 5,000) と文献量の prior の v19 で 0.386
- **天然物パネル:** ショートリストを 5,000 にすると正解が入る割合は 90% → 98%、文献量の prior で top-1 が 40% → 93%

読み取り:
- 解釈 1 (pool 外の分子は PubChem 本体にある) を支持する。PubChemLite (38.6 万構造) では足りず、PubChem 本体 (約 1 億構造) が要る
- ただし PubChem 由来の得点は、FPNet と文献量の prior で数千件の候補から正解を引き上げて初めて出ている。今の固定融合 / analog 単独では、窓あたり数千件の PubChem 候補を並べ切れない
- −0.055 は、EXP-0002 の推定 (pool 外 57% ≈ public 71 分子) から期待される規模より小さい。解釈 2 (クラス構成モデルのずれ) も残る

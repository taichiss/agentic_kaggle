# EXP-0008: 候補 pool の改善 (段 1) と改善前後の差分

- **日付:** 2026-10-28
- **コード:** `scripts/casmi26_baseline_cv.py --extra-pool pubchemlite --pool-window corrected`、集計は `scripts/casmi26_pool_diff.py` (→ `pool_diff.json`)
- **ランカーは変えていない** (固定融合 A と analog 単独 B のまま)。差分は pool だけ
- **LB:** 新規提出なし

## 変更内容

| | 改善前 (V17) | 改善後 |
|---|---|---|
| 構造 DB | COCONUT (prvsiyan 版) ∪ train | + PubChemLite (38.6 万構造、CC0) |

- **正解が pool に入るようになった:** NP drop で 242 分子が pool 外 → 234 分子が新たに入った (残り 8)。keep / other で落としていた 1 分子 (誤差 > 8.5 ppm の低質量分子) も拾えた
- **1 位は増えていない:** NP keep の A は 1 位 18 → 16、B は 99 → 94。ランカーを変えていないので、候補に入れるところまでが今回の改善
- ずれ補正と新しい窓で、PubChemLite による希釈の大半を取り戻した (NP keep の A は 0.183 → 0.194 で V17 と同値、fold0 は候補が 113.5 → 85 件に減り V17 を上回った)
- 残る 8 分子は質量の誤差が ±2.1 ppm 以内で、窓の問題ではない。COCONUT 版にも PubChemLite にも構造がない (トリテルペン配糖体、リン脂質など)

## LB への見込み (EXP-0002 のクラス構成で試算、未検証)

ΔLB ≈ p1·Δ(Class 1) + p2·Δ(Class 2) + p3·r·M(救済後)、p1 = 0.148、p2 = 0.285、p3 = 0.567

- A: Δ ≈ 0.148 × (+0.004) + 0.285 × (0.000) + 0.567 × r × 0.186 ≈ +0.001 + 0.105·r
- B: Δ ≈ 0.148 × (−0.005) + 0.285 × (−0.014) + 0.567 × r × 0.498 ≈ −0.005 + 0.282·r
- r (hidden test の pool 外の分子のうち PubChemLite にあるもの) が分からないので幅を持たせると、r = 30% で A +0.033 / B +0.080

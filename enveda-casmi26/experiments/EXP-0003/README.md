# EXP-0003: 質量スペクトルの原理から見た、候補 pool とランカーの失敗要因

- **日付:** 2026-10-27
- **コード:** `scripts/casmi26_ms_diagnostics.py`, `src/casmi26/analysis/ms_diag.py`, `scripts/casmi26_baseline_cv.py --precursor-window / --extra-pool`
- **対象:** EXP-0001/0002 と同じ query (NP 250 分子 / fold0 400 分子)。候補窓は pool=keep
- **LB:** 新規提出なし

## 問い

1. 候補 pool: precursor の質量は正しく読めているか。窓の中は何が占めているか。PubChemLite で pool 外を救えるか
2. フラグメント: 正解構造で説明できないピークは何か (特定の断片の見落とし / 組合せ (3 結合以上) の見落とし / 同位体 / H 移動 / 付加イオン)
3. 基準ピーク・類似度: 基準ピークは何か。precursor ピークが類似度を歪めていないか
4. ランカー: 1 位の誤りは分子式の違いか、同じ分子式の異性体か

## 結果 1: 候補 pool

### precursor 質量 (問題なし)

| | NP | fold0 |
|---|---:|---:|
| 中性質量の誤差 (スペクトル単位, 10/50/90%) | −0.6 / **+1.6** / +3.1 ppm | −0.1 / **+1.7** / +3.0 ppm |
| 分子単位の \|誤差\| 99% 点 | 6.0 ppm | 3.9 ppm |
| ±8.5 ppm 窓のカバー率 | 99.2% | 100% |
| ±5 ppm 窓のカバー率 / 候補数 (中央値) | 97.6% / 48.5 件 | 100% / 62 件 |
| 同位体ピークを precursor と取り違えた疑い (誤差 ≈ ±1.00336 Da) | 0 本 | 0 本 |

- +1.6 ppm の系統誤差がある (V17 の注記「timsTOF +1.4 ppm」と一致)。補正すれば窓を狭められるが、候補数の削減は 53 → 48.5 件程度で効果は小さい
- V17 の予備窓 (±30 ppm) は「±8.5 ppm 窓が空のときだけ」働く。PubChemLite 追加で窓に別候補が 1 件入り、誤差 > 8.5 ppm の正解 1 分子を取りこぼした

### 窓の中身: ほぼ同じ分子式の異性体

| | NP | fold0 |
|---|---:|---:|
| 候補数 (中央値) | 53 | 88 |
| 異なる分子式の数 (中央値) | **3** | **5** |
| 正解と同じ分子式の候補 (中央値) | **39.5** | **35.5** |
| 正解の分子式が窓内で唯一 | 4% | 4% |
| A の誤答 1 位が正解と同じ分子式 | 84% | 77% |
| B の誤答 1 位が正解と同じ分子式 | 87% | 81% |
| 誤答 1 位と正解の Tanimoto (中央値) | A 0.26 / B 0.36 | A 0.20 / B 0.23 |

→ 分子式の決定 (同位体パターン、質量欠損) を改善しても、ほとんど効かない。誤りの大半は**同じ分子式の、構造がかなり違う異性体**に負けている

### PubChemLite の追加

| 条件 (NP) | MRR@25 | カバー率 | 候補数 | analog 単独 |
|---|---:|---:|---:|---:|
| pool から除く (EXP-0001) | 0.004 | 3.2% | — | 0.009 |
| pool から除く + PubChemLite | **0.175** | **96.0%** | 88 | 0.488 |
| pool に残す (EXP-0001) | 0.194 | 99.6% | 53 | 0.535 |
| pool に残す + PubChemLite | 0.183 | 99.2% | 87.5 | 0.511 |

- 手元の PubChemLite (38.6 万構造) は COCONUT と重複 0 件、train とは 2.6 万件だけ重なる。それでも NP の正解構造の 97.6% を含む (fold0 の drug-like は 0.5%)
- COCONUT ∪ train にない天然物を救う効果は大きく、候補が増えて正解が薄まる代償は −0.011 と小さい

## 結果 2: フラグメント (MetFrag-lite)

### ピーク帰属 (強度シェア、正解構造 vs A の誤答 1 位)

| 区分 | NP 正解 | NP 誤答 | fold0 正解 | fold0 誤答 |
|---|---:|---:|---:|---:|
| precursor 本体 | 8.6% | 8.8% | 5.1% | 5.1% |
| precursor の同位体 | 1.7% | 1.7% | 1.0% | 1.0% |
| 断片 (H 移動なし) | **17.8%** | 13.9% | **18.1%** | 15.5% |
| ¹³C 同位体 | 1.6% | 1.3% | 1.7% | 1.6% |
| 断片 (±1〜2 H 移動) | **31.4%** | 28.4% | **43.0%** | 27.1% |
| precursor からの中性ロス | 0.7% | 1.4% | 0.1% | 0.2% |
| 断片からの連続ロス | 12.3% | **14.8%** | 5.8% | **11.5%** |
| 3 結合切断の断片 | 5.4% | 6.1% | 4.1% | 6.2% |
| 付加イオン担体つき断片 | 0.5% | 0.3% | 0.1% | 0.0% |
| 説明できない | **19.9%** | 23.0% | **20.8%** | 31.7% |

読み取り:
- **見落としている断片の種類は特定のものに偏っていない。** 正解と誤答の差がつくのは「H 移動なし / あり」の断片だけで、中性ロス・連続ロス・3 結合切断はむしろ誤答の方をよく説明する。異性体どうしは同じ汎用的なロスを共有するので、識別に役立たない
- **組合せ (3 結合以上の切断) の見落としは主因ではない。** 追加で説明できる強度は正解 4–5%、誤答 6% で差がない
- **同位体ピークは少ない** (1.6–1.7%)。+1H と ¹³C の取り違えも限定的
- **付加イオン別に見ると、Na⁺/K⁺/NH₄⁺ 付加体が弱い。** NP の `[M+Na]+` は precursor が強度の 30% を占め、説明できない強度が 26%。`[M+K]+` は 45%、`[M+NH4]+` は 42%。proton 付加体 (`[M+H]+` 21%、`[M-H]-` 8%) よりはるかに悪い
- **2 量体 `[2M+Na]+` (fold0 のスペクトルの 15%) は 96.6% が説明できない。** 97% で基準ピークが単量体 `[M+Na]+` (強度の中央値 74%)。hidden test には 2 量体の adduct がないので、fold0 CV の歪みの元になる

### スコア変種ごとの、断片チャネル単独の MRR@25

| 変種 | NP | fold0 | NP 結合数 > 34 (66 分子) |
|---|---:|---:|---:|
| V0 V17 そのまま (±0.01 Da, ±2H, 結合数 34 まで) | 0.238 | 0.620 | 0.115 |
| V1 結合数上限を撤廃 | 0.281 | 0.620 | **0.286** |
| V2 + 許容差 10 ppm | 0.304 | 0.630 | 0.323 |
| **V3 + 同位体ピーク除去** | **0.308** | **0.668** | 0.322 |
| V4 + 中性ロス・連続ロス | 0.243 | 0.544 | 0.266 |
| V5 + 付加イオン担体 | 0.232 | 0.537 | 0.260 |
| V6 V5 で H 移動を ±1 に制限 | 0.232 | 0.520 | 0.261 |
| V7 V0 で H 移動を ±1 に制限 | 0.248 | 0.625 | 0.113 |

- **結合数の上限 (34) が NP の 26% を素通りさせていた。** これらの分子では断片を 1 つも作らず、断片チャネルは実質使えていなかった (0.115 → 0.286)
- **許容差 0.01 Da は広すぎる。** H 移動なしの一致の質量誤差は中央値 7.9 ppm (NP) / 9.5 ppm (fold0)、90% 点 36 / 44 ppm で、偶然の一致を多く拾っている。timsTOF の精度なら 10 ppm で十分
- **同位体除去は fold0 で効く** (+0.038)
- **中性ロス・連続ロス・付加イオン担体を足すと悪化する** (V4: NP −0.065、fold0 −0.124)。どの異性体にも同じように当てはまるため
- 最良は V3。V0 比で NP +0.070 (+29%)、fold0 +0.048

## 結果 3: 基準ピークと precursor ピーク

| 正解構造での基準ピークの帰属 | NP | fold0 |
|---|---:|---:|
| 断片 (H 移動なし + あり) | 60% | 70% |
| precursor 本体 | **15.6%** | 6.7% |
| 説明できない | 11.5% | 17.6% |
| 連続ロス | 8.4% | 2.5% |

- NP の 30–45 eV では、21% のスペクトルで基準ピークが precursor (衝突エネルギーが低いと開裂が進まない)
- **precursor ピークは窓内の全候補が共有する。** そのため、別の異性体とのライブラリ類似度が水増しされる。類似度計算から precursor 付近 (m/z > precursor − 0.5) を除いた結果:

| 条件 | 融合 A | analog 単独 | ライブラリ単独 | 誤った異性体との lib 類似度 (中央値) |
|---|---:|---:|---:|---:|
| NP Class 2 (keep) | 0.194 → **0.245** | 0.535 → 0.545 | 0.053 → 0.053 | 0.575 → 0.524 |
| NP Class 1 (other) | 0.914 → 0.916 | 0.637 → 0.649 | 0.927 → 0.932 | 0.859 → 0.863 |
| fold0 Class 2 (keep) | 0.096 → **0.167** | 0.598 → 0.618 | 0.017 → 0.017 | 0.648 → 0.633 |

→ Class 1 を損なわずに、Class 2 の融合が +0.05〜+0.07 上がる。リスクの低い改善

## まとめ (原理ごとの結論)

| 問い | 結論 | 根拠 |
|---|---|---|
| precursor 質量・同位体の取り違え | 問題なし | 誤差 99% が 6 ppm 以内、取り違え 0 本 |
| 分子式の決定 | 改善余地が小さい | 誤答の 77–87% が同じ分子式 |
| 特定の断片の見落とし | **結合数 34 超の分子で全部見落とし** (NP 26%) | 上限撤廃で断片 MRR 0.115 → 0.286 |
| 組合せ (3 結合以上) の見落とし | 主因ではない | 正解と誤答で説明できる量が同じ |
| 質量許容差 | 広すぎる | 一致誤差の中央値 8–10 ppm、10 ppm 化で改善 |
| 同位体ピーク | 量は少ないが除去は有効 (fold0) | fold0 +0.038 |
| 付加イオン | Na⁺/K⁺/NH₄⁺ 付加体と 2 量体が弱い | 説明できない強度 26–97% |
| 基準ピーク・precursor | precursor が異性体の類似度を水増し | 除去で Class 2 +0.05〜0.07 |
| pool 外 | PubChemLite で大半を救える (NP) | カバー率 3.2% → 96% |

## 次に試すこと

1. **パイプラインへの反映 (すぐできる):** 類似度計算の precursor 除去 + 断片スコア V3 を既定にして CV を回し直す。LB 予測を事前に書いて提出する
2. **候補 pool に PubChemLite を追加。** 予備窓の発動条件も「空のとき」から見直す (例: +1.6 ppm 補正後の ±10 ppm 窓)
3. **異性体を見分ける証拠を増やす。** 誤りの大半が同じ分子式の異性体なので、FP 予測 (fold-safe FPNet / MIST) や順方向シミュレータ (ICEBERG) のような構造に敏感な特徴を、学習済みランカーに入れる
4. **CV の query を test にある adduct に限る。** fold0 は test にない 2 量体を 15% 含む
5. Na⁺/NH₄⁺ 付加体の断片則 (Na 保持断片、NH₃ 脱離後の [M+H]⁺ 系列) を、識別に効くか確かめてから入れる (汎用ロスは逆効果だった)

## 限界

- ピーク帰属は 1〜3 結合の切断と既知のロス表に基づく近似で、転位反応の網羅ではない。「説明できない」には未知の転位、共溶出、ノイズが混ざる
- 誤答は A の 1 位だけを比べた。B の誤答や 2〜10 位との比較はしていない
- 断片チャネルの MRR は単独で並べた場合の値で、融合後の効果は別途 CV で確かめる必要がある

PubChem は手元の PC で扱えた。CV では大きく伸びたが、LB では下がった

PubChem 本体（約 1.1 億構造）の索引を作り、窓ごとに文献量の多い候補を足して、文献量の prior で並べた。NP ホールドアウトの CV では +0.21 伸びたが、LB はこれまでの最良より −0.020 下がった。hidden test の分子は、NP ホールドアウトよりずっと文献が少ない。

自分の PC で PubChem を扱えるか 扱える7 分 / 10 GB

12 コア・メモリ 15 GB・空きディスク 909 GB の PC で、5.2 GB をダウンロードし、1 億 1,040 万構造の索引を 7 分（ピークメモリ 10 GB、ディスク 11 GB）で作れた。Kaggle 用の軽量版は 4.0 GB で、提出 kernel も 18〜39 分で完走した。

PubChem を足すと LB は上がったか 下がった0.248 → 0.228

これまでの最良（EXP-0008 の B、analog 単独）から、S1（analog + 断片 + 文献量 prior）で −0.020。事前の判定基準（+0.03）に届かず、この路線は採用しない。

やったこと

索引を作り、効果を確かめながら提出まで進めた

  1. PubChem FTP の Extras を 4 ファイル取得（5.2 GB）CID-Mass（分子式と質量）、CID-SMILES、CID-SID（登録数）、CID-PMID（文献数）。
  2. 質量順の索引を作成荷電種と複数成分を除いた 100–1500 Da の中性構造 1 億 1,040 万件。SMILES はディスク上に置き、窓の分だけ読む。文献量の prior は公開 kernel と同じ 0.25 ×（ln(1 + 登録数) + ln(1 + 文献数)）。
  3. 効果確認 1：正解は窓の中で文献量の何位かパイプラインを回す前の安価な確認。NP は 66% が 1 位、fold0 は中央値 2,674 位。
  4. 効果確認 2：CV（窓ごとに文献量の上位 100 件を追加）4 条件 × 6 通りの並べ方。重みは決め打ちで、検証データでは調整していない。
  5. Kaggle 用の軽量版索引（4,420 万件、4.0 GB）を非公開 Dataset として作成窓の上位 100 件の文献量の並びは、1,050 窓中 1,047 窓で完全版と一致。CV の数字も完全版とほぼ同じ。
  6. 予測を固定してから 2 本を提出S1（本命）と S2（文献量だけ、診断用）。

解釈

hidden test の分子は文献が少なく、文献量の prior が誤答を押し上げた

  1. NP ホールドアウトは、文献量を使う変更の評価に向かない。よく研究された天然物ばかりで、文献量だけで 66% が 1 位になる。天然物パネルの README にも「文献量の prior に有利」と注意書きがある
  2. hidden test の文献の多さは、NP ホールドアウトの 3 分の 1 程度。文献量だけの S2 は 0.116 で、NP ホールドアウトから期待される 0.337 の 0.34 倍だった。文献の多い別の異性体が上位に来て、正解が押し下げられる（fold0 と同じ現象）
  3. 公開 kernel が PubChem から得点できているのは、FPNet で構造を見分けているから。窓あたり数千件の PubChem 候補から正解を選ぶには、構造に敏感な証拠（指紋予測）が要る。今の analog と断片だけでは、PubChem の候補を足しても誤答が増えるだけになる
次に試すこと

PubChem の索引は手元に残し、構造を見分ける特徴量を先に作る

  1. 提出の基準は EXP-0008 の B（0.248）のまま。EXP-0009 の索引と kernel は、そのまま再利用できる
  2. 評価セットを作り直す。文献量を使う変更は、NP ホールドアウトだけで判定しない。文献の少ない分子（fold0 型）を混ぜるか、S2 の LB（0.116）に合う割合で NP と fold0 を混ぜた評価を使う
  3. 構造に敏感な特徴量を作る。fold-safe FPNet や MIST のような指紋予測ができれば、PubChem の候補も見分けられるようになる。そのときに PubChem の索引を使い直す
限界と注意

予測モデルと CV の両方に、まだずれがある

  • 予測に使ったクラス構成（EXP-0002）は未知数 2 つに式 2 本の推定で、文献量のように分子の性質で効き方が変わる変更には合わなかった
  • 軽量版の索引では、1,050 窓中 3 窓で境目付近の候補が完全版と違う。結果への影響は無視できると判断した
  • 窓あたりの PubChem 候補は文献量の上位 100 件に固定した。件数を変えた比較はしていない
  • 分子ごとの順位の CSV（正解の InChIKey を含む）を一度 git にコミットしてしまい、今は追跡から外してある。履歴（コミット 001aaa6）には残っている

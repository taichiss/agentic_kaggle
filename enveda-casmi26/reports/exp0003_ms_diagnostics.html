フラグメント 1 · ピーク帰属

見落としは特定の断片の種類に偏っていない。差がつくのは単純な開裂断片だけ

正解構造と、A の誤答 1 位の構造で、同じスペクトルのピークを帰属した（強度シェア）。各ピークは precursor → 同位体 → 断片 → ロス → 3 結合切断 → 付加イオンの順で、最初に当てはまった区分に入れる。

帰属の内訳（強度シェア）

正解 − 誤答（強度シェアの差、ポイント）

NPfold0

正解の方がよく説明できるのは「H 移動なし / あり」の単純な開裂断片だけ。中性ロス・連続ロス・3 結合切断は、むしろ誤答の方をよく説明する。異性体どうしは H₂O や CO のような汎用的なロスを共有するので、これらを足すと識別が悪くなる。

adduct 別：説明できない強度（NP、正解構造）

proton 付加体（[M+H]⁺ 21%、[M−H]⁻ 8%）に比べ、Na⁺・K⁺・NH₄⁺ 付加体は 26–45% が説明できない。Na⁺・K⁺ 付加体は precursor が強度の 30% を占め、開裂が進んでいない。hidden test の adduct は [M+H]⁺ 79%、[M−H]⁻ 16% なので、影響は限定的。

次に試すこと

すぐ効く修正 2 つと、異性体を見分ける特徴への投資

  1. パイプラインに反映して CV と LB を取り直す。類似度の precursor 除去と断片スコア V3 を既定にする。LB の予測を事前に書いてから提出する
  2. 候補 pool に PubChemLite を追加する。予備窓の発動条件も「窓が空のときだけ」から見直す（+1.6 ppm 補正後の ±10 ppm など）
  3. 異性体を見分ける特徴を学習済みランカーに入れる。誤答の大半は同じ分子式の別構造なので、FP 予測（fold-safe FPNet / MIST）や順方向シミュレータ（ICEBERG）のような構造に敏感な特徴が要る
  4. CV の query を test にある adduct に限る。fold0 は test にない 2 量体を 15% 含む
  5. Na⁺・NH₄⁺ 付加体の断片則は、識別に効くことを確かめてから入れる。汎用的なロスの追加は逆効果だった
この分析の限界

帰属は近似で、転位反応を網羅していない

  • ピーク帰属は 1〜3 結合の切断と既知のロス表に基づく近似。「説明できない」には未知の転位、共溶出、ノイズが混ざる
  • 誤答は A の 1 位だけと比べた。B の誤答や 2〜10 位との比較はしていない
  • 断片チャネルの MRR は単独で並べた値。融合後の効果は CV で確かめ直す必要がある
  • PubChemLite の効果は NP（天然物）でしか測れていない。drug-like な fold0 の正解は 0.5% しか含まれない

# Public notebook references

Versioned notebook references live in `asset-sources.toml`; downloaded copies live under ignored
`data/public-notebooks/`.

The initial references are community getting-started material. They are useful for understanding the
Kaggle runtime and basic submission path, but they are not authoritative for Rules, metric behavior,
or expected performance. Record the pulled notebook version/metadata before basing an experiment on
it.

# Evaluation

Use the organizer-maintained `tracking_cellmot` metric as the local fidelity target after the data
and baseline are acquired. Keep evaluation summaries and tiny synthetic fixtures here; predictions,
GEFF graphs, full labels, and generated reports belong under ignored `artifacts/`.

TRUST-LB does not require full CV. A one-sample graph/CSV round trip and structural submission
validation are the minimum gate before an explicitly authorized Kaggle notebook submission.

## 何が原因と考えられるか

G1→G2のLB +0.011は、元の統合アナログ順位特徴量を残す設計が有利という**示唆**である。G1の`each`は生成元の探索と順位用アナログ特徴量の双方へ入る。G2は後者を`merged`へ戻す。ただし、外部80分子の最終候補集合もG1とG2で20/80、並び順は32/80で異なった（1位は同じ）。従って+0.011を順位特徴量の単独効果と断定できない。厳密に分けるには、同じ候補集合を固定して`merged`/`each`の順位特徴量だけを切り替える追加評価が必要。

G2→G4のLB +0.005は、CE別検索を単純に流すより、元の最上位生成親を保ちながらCE別の親を多様化する方が良かったことを示す。それでもG4はG0より−0.005。ラベルなしのテスト400分子生成監査では、G4はG0から640候補を追加し、645候補を削除した。削除した構造が正解だったかは不明だが、Enveda-180の分子非重複200群ではG4が正解生成候補を3件救済し、別の3件を失った。候補の入れ替えが利得と損失の両方を生む経路は実在する。

外部80分子で同アダクト・装置・前駆体のCE別選択に適合したのは8/80（10%）で、テスト全400分子では279/400（69.75%）。外部80分子のG4改善は主に1分子の正解順位6→3で、テストの大半で起こる候補変更を代表しない。これはローカルとLBの方向が違った**可能な説明**であり、隠し正解がないため因果の証明ではない。外部80分子は正解候補54/80という選択済み代理パネルで、天然物寄りだがテストとCE測定の構成が違う。Enveda-180はCE組合せが近い一方、スクリーニング化合物で化学空間が違う。

## この結果から選んだ5本目

G5は元G0の生成候補を残してG4由来のCE別候補を追加する。テスト400分子のラベルなし監査ではG5の集合はG0∪G4と400/400で一致し、640候補追加・**削除0**、集合変更65/400。Enveda200群では正解生成候補がG0の8/200から11/200へ増え、救済3・喪失0。外部80分子ではG5親のMRRはG0と同じ0.353244、G5＋AはAより+0.000253だった。固定Aは過去にG0のPublic LBを0.477→0.479にし、今回G1を0.456→0.457にした。そこで5枠目は**G5＋固定A**を選び、提出ID`58461399`として受理された。現時点のPublic LBは**採点待ち**。G5単独をPublic LBへ提出していないため、この5本目の結果から候補和集合とMISTの効果を単独では分けられない。追加候補が誤候補として順位を下げる危険も残る。

# CE別候補生成：ローカルとPublic LBの照合（2026-11-17）

保存済み0.477親の候補プール・順位モデルを起点に、CE別スペクトルを候補生成へ使う位置を変えた。外部80分子のMRR@25は同じ分子と正解照合方法で親の全工程を再実行した値。Public LBはKaggle公式提出一覧の表示値で、小数第3位までしか読めない。親G0の提出IDは`57827264`、固定Aの提出IDは`58077626`。今回の4提出ID・CSVハッシュは`strategy/lb-submissions.jsonl`を参照。

## 何が原因と考えられるか

G1→G2のLB +0.011は、元の統合アナログ順位特徴量を残す設計が有利という**示唆**である。G1の`each`は生成元の探索と順位用アナログ特徴量の双方へ入る。G2は後者を`merged`へ戻す。ただし、外部80分子の最終候補集合もG1とG2で20/80、並び順は32/80で異なった（1位は同じ）。従って+0.011を順位特徴量の単独効果と断定できない。切り分けの第一段階として、生成経路を固定して順位特徴量だけを切り替える評価が必要だった。

この切り分けを外部80分子で追加実行した。生成元・初期Engine1生成候補をG0に固定し、**アナログ順位特徴量だけ**各CE検索へ切り替えた`rank-only`のMRR@25はG0 **0.353244**→**0.351348**（差−0.001896、分子単位ペアブートストラップ95%区間[−0.004872,+0.000060]）。G1は**0.350307**で、G1で正解順位が動いた5分子のうち4分子の変化を`rank-only`が再現した。これにより、ローカルG1低下の一部がアナログ順位特徴量に由来することは支持される。ただし`rank-only`でも後段の打ち切り後の最終Top25集合はG0から23/80分子で変わる。加えて対象はCE適合8/80の選択済み代理パネルで、**LBの−0.021を順位特徴量へ定量的に割り当てる根拠にはならない**。詳細は`docs/ce-analog-rank-only-external80-20261117.md`。

G2→G4のLB +0.005は、CE別検索を単純に流すより、元の最上位生成親を保ちながらCE別の親を多様化する方が良かったことを示す。それでもG4はG0より−0.005。ラベルなしのテスト400分子生成監査では、G4はG0から640候補を追加し、645候補を削除した。削除した構造が正解だったかは不明だが、Enveda-180の分子非重複200群ではG4が正解生成候補を3件救済し、別の3件を失った。候補の入れ替えが利得と損失の両方を生む経路は実在する。

外部80分子で同アダクト・装置・前駆体のCE別選択に適合したのは8/80（10%）で、テスト全400分子では279/400（69.75%）。外部80分子のG4改善は主に1分子の正解順位6→3で、テストの大半で起こる候補変更を代表しない。これはローカルとLBの方向が違った**可能な説明**であり、隠し正解がないため因果の証明ではない。外部80分子は正解候補54/80という選択済み代理パネルで、天然物寄りだがテストとCE測定の構成が違う。Enveda-180はCE組合せが近い一方、スクリーニング化合物で化学空間が違う。

テスト全400分子を正解ラベルなしで凍結済みEngine1のFPNet・V1FE・LightGBM順位まで通すと、G4はG0比で**113/400分子**、G5は**63/400分子**のEngine1 Top25構造集合を変え、両条件ともEngine1のTop1変更は0件だった。G5で生成追加した640候補のうち**352候補が58分子のEngine1 Top25へ入った**。候補追加が順位段階まで届くことを示すが、これはEngine1中間順位で、Engine2・PubChem・最終融合後の提出順位でも、正解を使った精度でもない。候補集合が変わらずTop25だけ動く例もあるため、差を候補追加だけに帰属しない。詳細は`docs/ce-union-full-test-engine1-rank-20261117.md`。

## この結果から選んだ5本目

G5は元G0の生成候補を残してG4由来のCE別候補を追加する。テスト400分子のラベルなし監査ではG5の集合はG0∪G4と400/400で一致し、640候補追加・**削除0**、集合変更65/400。Enveda200群では正解生成候補がG0の8/200から11/200へ増え、救済3・喪失0。外部80分子ではG5親のMRRはG0と同じ0.353244、G5＋AはAより+0.000253だった。固定Aは過去にG0のPublic LBを0.477→0.479にし、今回G1を0.456→0.457にした。そこで5枠目は**G5＋固定A**を選び、提出ID`58461399`として受理された。現時点のPublic LBは**採点待ち**。G5単独をPublic LBへ提出していないため、この5本目の結果から候補和集合とMISTの効果を単独では分けられない。追加候補が誤候補として順位を下げる危険も残る。

固定1,000と天然物パネルには実在する0.477親順位がないため、モデル候補スコアだけを比較した。親80件では分子式内融合を元順位RRF（重み0.25）に一度だけ反映し、元1位と候補集合を全件固定した。親80件の正解候補不在はMRRに0として含めた。固定1,000と親80は分子単位5,000回、天然物は同一構造のソース間重複をまとめた構造key単位2,000回のbootstrap。区間はM5と各対照の対応差に対するもの。

天然物のソース別M5−AはGNPS 3,532件で+0.001123 [−0.000513, +0.002798]、RIKEN 1,181件で+0.001420 [−0.000349, +0.003340]、MassBank 688件で+0.002219 [−0.000662, +0.005244]、enveda-np-examples 24件で+0.000992 [0, +0.002976]。候補25件層1,017件のM5−Aは+0.001597 [−0.001204, +0.004417]、M5−旧M4は+0.000345 [−0.002331, +0.003091]。候補2–5件層2,204件ではM5−A +0.000703 [−0.001173, +0.002502]、6–24件層2,204件では+0.001824 [+0.000023, +0.003734]だった。天然物パネルは事後構築かつ候補数可変なので、MRR絶対値を固定25候補、親80、Public LBと直接比較しない。

**監査**: strict M1の固定1,000件の候補スコアを最終checkpointで再推論し、保存済みvalidation順位と全件一致。旧M4の固定1,000/親80/天然物MRRは既存レポートと一致。天然物7,112分子×ソースの候補順、真値位置、Aとstrictの保存順位は全件照合。既存の天然物パネル監査では、検証クエリー構造の訓練構造重複は0で、訓練構造はdecoy候補にのみ現れる。単一候補1,687件は別集計。保存親80は1位全件固定。スコアや候補集合は評価後に変更していない。

**判断**: 固定1,000と親80では旧M4より低く、天然物での旧M4との差も区間が0を含む。M5を5枠目のPublic LB提出候補から外す。Kaggle操作は行っていない。

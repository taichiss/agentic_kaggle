# MS/MS 2スペクトル混合の比較計画（2026-11-16）

## 目的と主対照

同分子式候補の順位付けに対し、訓練時のスペクトル混合そのものが効くかを検証する。主対照は **EXP-0025 / BCF-A**（2048ビット、12,000更新、Public LB 0.479）。これは今回の実験と同じ自作分子式条件付きTransformer、同じ教師FP、分割、訓練キャッシュ、0.477親Notebook、順位融合0.25、1位固定であり、混合の有無だけを変えられる。

B（4096ビット、Public LB 0.478）は**参考比較**とする。FP長が異なるため、AとBの差を混合効果として扱わない。C（公式MIST、0.478）とF（B/C融合、0.477）はモデル・学習元・採点可能率が異なり、混合の直接対照にはしない。

## 初回の訓練条件

| ID | 2本目のスペクトル | 混合と教師 | 目的 |
|---|---|---|---|
| M0 | なし | 保存済みAを対照にする | 無混合の基準 |
| M1 | 同一分子の別測定 | 生のピーク強度を混合。教師FPは元の分子のまま | 混合演算そのものと測定変動への耐性 |
| M2 | 異なる訓練分子、同分子式 | 主分子85–95%、相手5–15%。教師FPと順位損失の正解は主分子 | 共分離ピークへの耐性 |
| M3（探索） | 異なる訓練分子、同分子式 | 50:50。FP教師を50:50の軟らかいビット値にし、両分子を重み付き正例として扱う | 強い混合が異性体の識別を鈍らせるかを検査 |

2026-11-16の追加指示に従い、M1・M2・M3をそれぞれ1回学習し、3条件とも同じ親Notebook経由で提出する。最初の3本のPublic LBとローカルのペア比較を見て、残り最大2枠の変更条件を決める。M0の保存済み重みを使う前に、変更した訓練コードの無混合経路が既存Aの固定チェックポイント／損失履歴を再現することを小規模に確認する。再現しない場合は無混合を同じコードで再学習して対照を作る。

## 全条件で固定する項目

- Aと同じ分子非重複train/validation、2,430,328採用スペクトル、2048ビットMorgan半径2教師、CHNO表、幅128・2層・4ヘッド、seed `20261107`、batch 128、学習率0.0003、12,000更新、同式負例、BCEと順位損失の重みを使用する。
- 混合サンプルは訓練分子のみから作り、validation分子を相手側にも使用しない。クエリー分子・元スペクトル・負例の乱数列はAと同じにし、2本目と混合係数には独立した乱数列を使う。
- 混合は訓練更新の25%のクエリーに適用する。M1/M2で適格な相手がなければ元スペクトルを使用し、適格率を分子・スペクトル・`ingest_lib`ごとに報告する。条件で混合実施率が異なれば解釈時に明記する。
- 2本は同じイオンモード・アダクト・測定ライブラリ・装置に限定し、前駆体m/zは20 ppm以内、両方の衝突エネルギーが既知なら差10 eV以内、欠損なら両方欠損に限定する。元の学習キャッシュではソース列が一定値なので、元のtrain行に厳密に突き合わせた別の測定ライブラリ・装置・衝突エネルギーmetadataを使う。アダクトIDが0の行でも極性を独立に照合する。M2/M3は同じ分子式の別構造のみ。適格率が低い場合も無断で条件を緩めず、緩和案と対象件数を別に記録する。
- 生のm/zと線形強度を20 ppm程度でマージして混合し、その後に強度を再正規化して上位96ピークを選ぶ。加工済みの平方根・対数強度やCHNO割当テンソルを平均しない。親分子式・アダクト・衝突エネルギーは主分子の測定条件を使い、M1/M2の不一致がないか検査する。
- 推論時のスペクトル処理、FP候補集合、soft Tanimoto、同分子式内だけの順位融合0.25、1位固定はAのまま。

## 評価と判定

1. 同じ1,000検証分子×同分子式25候補でモデル単独のMRR@25・Top-1・正解順位を、分子単位のペア差としてA/M1/M2/M3で比較する。構造類似度の高い候補群、ライブラリ、装置、混合適格／不適格で層別する。
2. 同じ保存済み0.477系のラベル付き80分子入力順位に各モデルを適用し、親込みMRR@25と改善・悪化分子数を見る。この80分子は隠しテストではない。
3. M1・M2・M3はAと同じ0.477親Notebook・候補集合・1位固定で提出する。5枠のうち残り最大2本は、初回3本のPublic LBと親込み80分子のペア結果から、融合重みや最良条件の組合せを事前に決めて投入する。Public LBは小数第3位で、保存済み親テスト400分子のうち複数候補は12分子のみなので、ローカルのペア比較と別々に解釈する。

主な失敗仮説は、異性体同士の混合で識別ピークが相互に入り、モデルが両候補を曖昧に高く評価すること。M1とM2を分けるのはこの影響と測定変動への耐性を区別するため。M3は効果の検証というより、この失敗仮説の強度試験とする。

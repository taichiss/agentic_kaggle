# A/B/C/F のローカル評価と Public LB の小規模照合（2026-11-17）

既存台帳の完了済み提出だけを使用した。A は `EXP-0025-mist-12k`（提出 58077626）と同じ checkpoint を指す `EXP-20261110-bcf-a` のローカル値で、B/C/F も同じ 0.477 親 notebook、候補集合、同分子式内 RRF 重み 0.25、1 位固定の提出である。Kaggle への新規提出は行っていない。

| 条件 | 固定 1,000 分子・25 同分子式候補（モデル単独 MRR@25） | 保存済み親 80 分子（親順位込み MRR@25） | Public LB 表示値 |
| --- | ---: | ---: | ---: |
| A | 0.391255 | **0.355765** | **0.479** |
| B | 0.432768 | 0.353125 | 0.478 |
| C | 0.401203 | 0.353899 | 0.478 |
| F | **0.438993** | 0.355516 | 0.477 |

固定 1,000 パネルなら **F を選び、A は 4 位**となる。保存済み親 80 パネルなら **A を選び、Public LB の表示値でも A が 1 位**だった。後者でも残りの順序は一致しない。特に 80 パネルの F は 2 位だが Public LB 表示値は最下位である。1,000 パネルの C/F は公式 MIST が採点できた 664/1,000 分子のみを計算し、欠損を 0 として全体 MRR に入れた。親 80 では C/F の採点不可の分子式群が 6 件あり、元順位を保持した。異なる欠損処理と候補分布も順位差の解釈に影響する。

Public LB の B と C は小数第 3 位で同点なので、**表示値に中間順位を与えた記述的 Spearman 順位相関**なら計算できる：固定 1,000 は **−0.949**、親 80 は **+0.316**。Public LB で同点でない 5 組に限ると、ローカルの同順はそれぞれ **0/5 組**、**3/5 組**。未丸めの B/C の順序が不明なので、真の順位に対する正確な Spearman 値は計算できない。B>C または C>B のどちらかと仮定した値は、固定 1,000 が −0.8 または −1.0、親 80 が +0.2 または +0.4 となる。

これは **4 条件だけ**の照合で、Public LB は **小数 3 桁**に丸められている。順位相関は推定精度も汎化性も評価できない。A と B/C の表示差 0.001、A と F の差 0.002 を個別分子の効果量や将来の提出予測へ変換できない。1,000 パネルはモデル単独、親 80 は選択された代理集合（正解が候補内にあるのは 54/80）であり、隠しテストとは母集団も候補数も違う。両ローカル MRR と Public LB の**絶対値は比較しない**。

過去の A/B/C/F では親順位込み 80 パネルだけが **A を選ぶ**という粗い選択を再現した。そのため M1～M4 の 1,000 パネルでの順位改善を、そのまま LB 改善と扱わない。一方、親 80 の M1/M2/M3/M4 は全て A より低いものの、各ペア差の 95% ブートストラップ区間はすべて 0 を含む。M1 と M4 の差は特に小さい。この 80 件だけで各モデルの隠しテスト結果を確定できず、提出済み Public LB の実測を優先して判断する。

# M1 の CE・近接ピーク処理を揃えた再学習（2026-11-17）

## 変更条件と監査

元 M1 は、同一分子・同一ソース・装置・アダクト・極性で混合相手を選んだが、複数値の衝突エネルギーを `meta` 内の平均CEで単一値と区別せず許していた。また20 ppm以内のピークをまとめる際の代表m/zには強度重心を使い、M2/M3が共通で使う最大強度ピークの実測m/zとは異なっていた。

修正版 `src/mist_formula/train_mix_same_ce_strict.py` は、ペア索引に `ce_kind` を含め、kind 2（複数値）を除外する。kind 1 のCE差は元 `meta` の平均値でなく同じ source metadata sidecar の `ce_ev.npy` で10 eV以内と判定する。kind 0 はkind 0とだけ組み合わせる。近接ピークはM2/M3と同じ `mixup_pairs.merge_peaks` で統合し、最大強度ピークの実測m/zを残して上位96ピーク・CHNO候補を再生成する。分子非重複split、訓練分子・スペクトル、CHNO 3,038組成、2048ビットFP、幅128・2層・4ヘッド、seed `20261107`、12,000更新、混合確率0.25、主スペクトル比0.25～0.75は固定した。**旧M1との差はCEルールとピーク統合方法を合わせた効果であり、どちらか一方の効果に分解できない。**

12,000更新の独立した乱数リプレイは旧M1の試行383,036・成立190,452を元manifestと完全一致で再現した。旧成立のうち138,595件（72.77%）にkind 2が含まれた。修正版の試行は382,959・成立59,258（全1,536,000学習例の3.86%）で、内訳はkind 1:1が36,177、kind 0:0が23,081、kind 2と0/1交差はともに0。`enveda-180`の成立数は112,235から569へ減った。失敗後の混合乱数系列は変わるため、成立数の差131,194件を「元ペアの削除数」とはみなさない。ペア別・ソース別件数、入力・実装SHAは `data/derived/mist-mixup-20261116/M1-ce-strict-sharedmerge/pair-audit.json`。

無混合1ステップの損失 `1.2721483707427979` はAと完全一致。合成metadataテストはkind 2を相手・主スペクトルから除外し、kind 0/1交差を許さず、kind 1のsidecar CE 20/25 eVを許可・20/40 eVを拒否することを確認した。近接ピークの代表m/zとCHNO入力順が共有mergeと同じことも確認し、`tests/test_m1_ce_strict.py` は2件通過。共有merge導入前の中間runはstep 1,000で停止し、checkpointを作らず `M1-ce-strict/manifest.json` に理由とソース／ログSHAを保存した。評価・提出には使わない。

独立レビューでは実際の受理ペア1組について、修正版の`Cache.batch`とM2/M3共通の`mixed_batch`が出す9テンソルのバイト一致を確認した。元のCE条件・ピーク統合差以外の必須不具合は見つからなかった。学習時ソースSHA `f997b986…` をmanifestと一致させて保存するため、同trainerの長い説明文字列2行は`ruff`のE501のみ例外とし、他の対象には通常のlintを適用する。

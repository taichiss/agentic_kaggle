## Detailed Notes

### EXP-0001: RT・CCS 回帰

元資料との双方一対一の対応候補から、単位を確認したRT 1,131,351行（Enveda 1,126,734、
MassBank 4,617）と CCS 1,084,656行（Enveda）を使用。RT は分、CCS は Å²。学習ラベルに
測定 ID や答えを使わず、構造由来の RDKit 記述子・Morgan fingerprint、前駆体 m/z、
付加イオン、極性、機器種、ソースを特徴量に使用。データと候補対応の限界は ADR 0006 を参照。

目的変数ごとにラベルのある行を `ingest_lib` で層化して 90:10 に分割した。各ラベルは
１分割のみで、モデル選択にも使っているため独立した最終テストではない。MAE が小さいほど良い。

| モデル | RT MAE（分） | RT RMSE（分） | CCS MAE（Å²） | CCS RMSE（Å²） |
| --- | ---: | ---: | ---: | ---: |
| ソース別中央値 | 0.6805 | 1.0114 | 29.1248 | 41.2206 |
| Ridge | 0.4347 | 0.7128 | 6.5697 | 11.9488 |
| LightGBM | 0.3649 | 0.6081 | 6.1765 | 11.4892 |

RT の LightGBM は Enveda 検証112,674行で MAE 0.3556分、MassBank 検証462行では
2.6344分。行分割のRT検証113,136行のうち112,665行は学習側と同じ `inchikey14` を持つ。
補助的な `inchikey14` 非重複分割では LightGBM の RT MAE 0.3684分、CCS MAE 6.2781 Å²。
互変異性体正規化は未実施であり、ADR 0005 の正式な未知構造評価とは異なる。

別の探索評価では MS-DIAL の対応候補 CCS 2,704行を追加した。実測か予測かの由来は未確認。
ソース層化検証の MS-DIAL 270行では中央値、Ridge、LightGBM の MAE がそれぞれ
29.3786、7.1742、4.5885 Å²。構造非重複検証291行の LightGBM MAE は4.6325 Å²。
主評価と異なるラベル集合であり、実測値への汎化を保証しない。

最良モデルをラベル全体で再学習し、RT の未取得1,408,257行と CCS の未取得1,454,952行に
予測した。うちそれぞれ1,284,096行、1,385,823行はラベル付き学習例のないソースであり、
評価値をそのまま適用できない。RT には負値32件があり、未補正の生予測として扱う。
出力の `*_prediction_valid` で正・有限の予測を区別する。
予測は欠損の真値ではなく、hidden test の実測RT・CCSを示すものでもない。

本計算は Python 3.12.3、RDKit 2026.03.3、LightGBM 4.7.0、scikit-learn 1.9.1、
pandas 3.1.0、NumPy 2.5.4、CPU 6 threads、seed 20261027、主実行約98秒
（事前の分子特徴量計算は別）。再実行手順は `src/metadata_prediction/README.md`。
入力、分割ごとの件数・全モデルの値・バージョンは Git 管理外の
`data/derived/metadata-regression-final/metrics.json`、予測は同ディレクトリに保存。
予測・生データ・モデル重みは Git に含めない。

### EXP-0002: 溶媒名の探索的分類

MassBank の一対一対応7,131行のうち、元テキストでアセトニトリルとメタノールの
いずれか一方だけを識別できる4,969行を使用。両方・識別不可2,162行を評価から除外。
分子の物性予測ではなく、過去の測定記録に２種類のどちらの名前が含まれたかを分類する。
溶媒比率・添加剤・グラジエントは対象外。MassBank 単一ソースで層化9:1。

| モデル | Accuracy | Balanced accuracy |
| --- | ---: | ---: |
| 多数派 | 76.86% | 50.00% |
| ロジスティック回帰 | 92.56% | 87.86% |
| LightGBM | 95.17% | 92.60% |

行分割では学習と検証に328の共通構造があり、構造非重複では LightGBM accuracy 92.08%、
balanced accuracy 87.05%。contributor を丸ごと除くと BAFG は32.55%（1,149行）、
Athens_Univ は6.09%（345行）で、施設ごとにクラスが偏るため単純比較はできない。
異なる測定施設・条件での汎化が不安定であり、実測条件を推定値で置き換えない。
96,750行の参考予測は未知・混合溶媒にも２択を強制する。結果・混同行列と予測は
Git 管理外の `data/derived/metadata-solvent/full/`、手順は `src/metadata_prediction/README.md`。

### EXP-0003: 同系列装置のデータへの限定

テストの装置表記は `timsTOF`、同じ系列で取得された Enveda-180 の元データには
Bruker timsTOF Pro 2 とある。テスト parquet から型番・個体 ID・LC条件の一致は確定できない。
同じ Enveda 検証行を使い、同じ特徴量と LightGBM で Enveda のみと他ライブラリを加えた
場合を比較した。RT 混合学習は MassBank 4,155行を追加し、CCS 混合学習は由来未確認の
MS-DIAL 2,434行を追加した（いずれも行分割の学習行数）。

| 目的変数・検証 | 検証行数 | Enveda のみ MAE | 混合 MAE |
| --- | ---: | ---: | ---: |
| RT・ソース層化行分割 | 112,674 | 0.34894 分 | 0.35555 分 |
| RT・構造非重複 | 111,120 | 0.35331 分 | 0.35894 分 |
| CCS・ソース層化行分割 | 108,466 | 6.17646 Å² | 6.17728 Å² |
| CCS・構造非重複 | 107,125 | 6.27807 Å² | 6.28100 Å² |

同一行における絶対誤差の差（Enveda限定−混合）を `inchikey14` の構造単位で2,000回
bootstrap した条件付き95%区間は、RT 行分割 −0.00711〜−0.00611分、構造分割
−0.00669〜−0.00464分。CCS はそれぞれ −0.00594〜0.00423 Å²、
−0.01176〜0.00569 Å²。これは固定した学習モデルと今回の評価データ上の区間であり、
異なる学習セットの反復や装置の因果効果を測るものではない。RT の違いは約0.4秒と小さく、
測定条件・化学空間・追加例の件数やラベル品質の影響を装置そのものと分離できない。
構造分割は互変異性体正規化なしで、NP例を用いた独立評価でもない。

詳細・予測・再実行コマンドは `data/derived/instrument-comparison-full/` と
`src/metadata_prediction/regression.md` を参照。Kaggle の MRR@25 は評価していない。

### EXP-0004: 分子・ソースを考慮した検証と CCS クラスタモデル

RT または CCS のある1,134,055行を対象に RDKit 2026.03.3 で互変異性体の正規化後に
InChIKey の第１ブロックを生成し、ソースを跨いでも同じキーが同じ分割になるようにした。
公式概要のマッチング仕様に沿うが、公式 notebook 本文との実装同一性は未確認。
分子の検証割当を再現可能な乱数で1,024回試し、RT/CCS ごとのソース別検証行率が10%に
近いものを選択。ラベル値や検証性能は分割選択に使っていない。鍵生成失敗0、訓練166,119
分子・検証18,364分子、共通分子0。ソースごとの検証率10.005〜10.071%。
MS-DIAL の由来未確認 CCS は共通分割の対象だが、以下の CCS 学習・評価には含めない。

| CCS モデル（Enveda） | 学習行 | 検証行 | 行 MAE | 分子を均等重みとした MAE | RMSE |
| --- | ---: | ---: | ---: | ---: | ---: |
| 従来 LightGBM | 976,112 | 108,544 | 6.24160 Å² | 6.22356 Å² | 11.57308 Å² |
| 容量増 LightGBM（700 trees / 63 leaves） | 976,112 | 108,544 | 6.11198 Å² | 6.09441 Å² | 11.45161 Å² |
| 4クラスタ別 LightGBM | 976,112 | 108,544 | 6.29207 Å² | 6.27053 Å² | 11.59875 Å² |

クラスタ法は、訓練側だけで標準化した分子記述子と前駆体m/zを4群に MiniBatchKMeans で
分け、各群に LightGBM を学習。検証側の実測 CCS はクラスタ決定に使っていない。
図を見た後の探索的領域「実測230〜290・予測160〜210 Å²」は、標準1,651行、
容量増1,638行、クラスタ別1,648行。今回のクラスタ法は MAE も帯も改善しなかった。
容量増モデルの選択・報告は同一分割であり独立テストではない。
分子分割の標準モデルについて、後述の探索的な実測230〜290・予測160〜205 Å²の領域に
絞ると1,630/108,544行（1.50%）、その群の MAE は71.65 Å²、全絶対誤差の17.24%。

同一分子分割で RT LightGBM の Enveda 検証112,730行は、Enveda限定学習で MAE 0.35311分、
MassBank を加えた学習で0.35959分。後者の MassBank 検証465行は MAE 3.31307分。
可視化、詳細と再実行手順は `src/metadata_prediction/ccs-cluster-experiment.md`、
`molecule-source-split.md`、出力はコンペ配下の `data/derived/`。

元の行分割の図を見た後に定義した別領域（実測230〜290・予測160〜205 Å²）では
1,654行が検証全体の1.5%を占め、全絶対誤差の17.6%を占める。元の Enveda データにも
高い CCS が記録されており、全例が単量体付加イオン。197行には同じ構造キーの二量体で
RT差10秒以内・CCS差5 Å²以内の例があるが、同領域の事後選択による偏りがある。
混合物や誤割当の証明ではなく、生測定の追跡が必要。診断コードと集計は
`src/metadata_prediction/ccs_band_diagnosis.py`、`data/derived/ccs-band-diagnosis/summary.json`。

### EXP-0005: 二量体観測と CCS 補正の探索

Enveda の候補を互変異性体正規化分子キー・元InChIKey14・極性・H/Na付加種で結び、
RT差10秒以内の単量体と二量体を分子×付加種で集計した。検証3,863組で二量体／単量体
CCS比の中央値1.380、四分位範囲1.341〜1.413、訓練34,600組の中央値1.379。対応は
測定ランの同一性や元の完全な立体構造の一致を保証しない。単量体の実測 CCS が既知という
参考条件では、二量体 CCS を単純2倍すると MAE 118.12 Å²、訓練中央値を掛けると
10.92 Å²。これらは未知行を推定するモデルの精度ではない。
別化合物の [TIMS 測定研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC12132801/) では、
二量体が移動度分離後に解離して単量体 m/z に二量体由来の移動度が現れた例が報告されている。
今回の帯との整合性はあるが、個別の元測定を確認するまで同じ現象と断定しない。

EXP-0004 の分子非重複分割で、分子ごとの構造特徴から「Enveda で `[2M...]` が一度でも
観測されたか」を LightGBM で分類。訓練163,946分子・検証18,145分子で交差0、AUC 0.771、
閾値0.5で適合率0.666・再現率0.609。ただし非観測は物理的に二量体を形成しない証拠ではない。
単量体表記かつ二量体観測予測確率0.5以上の行に対して、予測済み CCS を2倍すると
MAE 6.242→59.269 Å²、訓練ペアの中央値1.379倍では25.175 Å²。単量体表記の誤差帯に
限れば中央値補正で MAE 71.650→37.208 Å²だが、32,372行が変更され全体は悪化。
実際の `[2M...]` 表記に2倍する場合も、元モデルがアダクトを使用しているため二重補正になり、
全体MAE 80.181 Å²まで悪化した。検証の正解値は予測・補正の判定には使わない。

追加の探索では訓練分子を２群に分け、片側で surrogate 回帰を学習し、もう片側の out-of-fold
誤差帯を使って判別器を学習した。確率0.1以上・係数1.379で927行を補正、事後定義の帯
1,630行中128行を検出し、全体MAE 6.242→6.675 Å²。誤差帯の定義は以前の検証図を見た後に
設定しており、この検証は完全に独立した最終評価ではない。いずれも二量体や誤割当を証明する
ラベルではなく、後段の加算や補正を採用しない。詳細は `src/metadata_prediction/` の
`dimer-pair-audit.md` と実験スクリプト、結果は `data/derived/` の各対応ディレクトリ。

### EXP-0006: CCS 異常帯の分子構造と生測定の追跡

EXP-0004 の分子非重複検証で事後的に定義した領域（実測 230〜290、予測 160〜205 Å²）には
1,630 行、545 正規化分子があり、全絶対誤差の 17.24% を占める。行には衝突エネルギーの
繰り返しが含まれる。H/Na の候補に絞った 1,594 行のうち、元の完全 InChIKey と極性が同じ
二量体記録があり、RT 差 10 秒以内かつ逆移動度差 0.01 以内のものは 137 行・52 分子。
領域は高 CCS を見てから選択しており、二量体起因の割合の推定ではない。

BOVAEDDVUDIXQV-UHFFFAOYSA-N（Z1688230646）では、元の単量体 [M+Na]+
(enveda_011899_09) は m/z 293.090088、RT 196.61 秒、1/K0 1.16、CCS 243.12 Å²、
モデル予測 177.86 Å²。二量体 [2M+Na]+ (enveda_011899_08) は m/z 563.190988、
RT 196.40 秒、1/K0 1.16、CCS 237.59 Å²。元の逆移動度は小数点第２位で記録されている。

公開元の試料対応表に基づき [MassIVE MSV000102122](https://massive.ucsd.edu/ProteoSAFe/dataset.jsp?accession=MSV000102122)
の pool 373 正極性測定の生データを取得した。RT 191〜202 秒、26 MS1 フレーム、各 m/z
±0.003 Da の抽出で、単量体 m/z に 1/K0 約 0.806 と 1.127 の２群が見られ、後者は二量体
m/z の約 1.123 の群と重なる。この窓のクロマトグラム相関は高 1/K0 群と二量体で 0.903、
低 1/K0 群と二量体で 0.669。窓は事後選択であり因果の証拠ではない。OpenTIMS の
オープンソース変換の絶対移動度は Bruker の校正と照合しておらず、公開メタデータの
1.16 との数値一致は前提にできない。移動度分離後の解離、同重体などの重なり、抽出時の
群の選択は今回の観測だけでは区別できない。類似する解離は別の化合物で
[報告](https://pmc.ncbi.nlm.nih.gov/articles/PMC12132801/)されている。

別の例 DSHCBUGATITVQL の２試料は元の InChIKey とカタログ ID が異なる鏡像異性体。
40 eV の [M+H]+ はそれぞれ CCS 181.91、255.56 Å²、1/K0 0.87、1.23、
RT 174.00、174.36 秒だった。スペクトルの強度コサインは約 0.9995（0.01 Da 以内で
貪欲に対応）だが、別試料・別測定であり同一試料の反復ではない。立体情報を取り除いた
モデル入力は同じ構造を表し、両方の予測は約 183.38 Å²。構造の正規化で情報が失われる
一方、差の原因が立体化学自体とは決められない。

異常帯と同じアダクト・近い m/z の対照についてそれぞれ 281 分子を比較した探索では、
特定の官能基だけで異常を説明できる明白な共通性は確認できなかった。選択は事後的であり、
因果推定ではない。再現コードは src/metadata_prediction/ccs_ion_mobility_audit.py、
ccs_structure_audit.py、raw_bova_mobilogram.py、plot_enantiomer_spectra.py。
生データのファイルサイズ確認とローカル SHA-256 は
data/source/enveda-180/raw/pool373-positive-manifest.json に保存（提供元ハッシュとは未照合）。
図と結果は data/derived/ccs-raw-bova/、ccs-raw-case-study/、ccs-structure-audit/。
